What is machine learning?

Normal programs follow rules a person wrote. Machine learning flips this: you show the computer many examples and it works out the rules itself. Show it thousands of house sales and it learns how size relates to price.

Supervised learning

Examples come with the right answer. The model learns to predict it. Two kinds: regression predicts a number (price, temperature); classification predicts a category (spam or not). My internship work.

Unsupervised learning

No answers given. The model finds structure on its own, like grouping customers with similar habits (clustering).

Reinforcement learning

An agent learns by trial and reward, like a game-playing program or a robot learning to walk.

Logistic regression

Fits a straight boundary. Fast and easy to explain, but cannot bend around curved groups.

k-Nearest neighbours

Look at the k closest examples and take a vote. k=1 memorises noise; a large k blurs detail.

Decision tree

Asks yes/no questions on one feature at a time. Deep trees memorise the training set.

Random forest advanced

Trains many trees on random resamples and averages them. Averaging cancels out individual errors, so it is usually far more stable.

Model evaluation: is it actually good?

A model outputs a score from 0 to 1. Where you place the threshold decides who is labelled positive, and every choice trades one kind of mistake for another. Slide it.

Precision

Of everything I flagged positive, how much really was? Matters when false alarms are costly.

Recall

Of all real positives, how many did I catch? Matters when missing one is costly (disease screening).

ROC curve and AUC

Plots catch-rate against false-alarm rate across all thresholds. Area under it (AUC) summarises quality: 0.5 is a coin flip, 1.0 is perfect.

Regression metrics

For numbers: MAE (average gap), MSE or RMSE (penalises big misses), R² (share of variation explained).

The same ideas as real Python code

Everything above, written the way it is done in practice with pandas and scikit-learn: clean, encode, scale, train, evaluate in one reproducible pipeline.

import pandas as pd
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.compose import ColumnTransformer
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.pipeline import Pipeline
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import classification_report

df = pd.read_csv("data.csv")
X, y = df.drop(columns="target"), df["target"]
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42, stratify=y)

prep = ColumnTransformer([
    ("num", Pipeline([("fill", SimpleImputer(strategy="mean")),
                      ("scale", StandardScaler())]), ["age", "salary"]),
    ("cat", OneHotEncoder(handle_unknown="ignore"), ["city"]),
])
model = Pipeline([("prep", prep),
                  ("clf", RandomForestClassifier(n_estimators=200, random_state=42))])

print(cross_val_score(model, X_train, y_train, cv=5).mean())   # honest estimate
model.fit(X_train, y_train)
print(classification_report(y_test, model.predict(X_test)))

For regression swap in LinearRegression or RandomForestRegressor and judge with mean_squared_error and r2_score.
